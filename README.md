# FortiBlockList

This repository uses a GitHub Actions workflow to keep several host lists up to date.

## Workflow steps
1. Download the latest lists from the sources below.
2. Clean the files by removing unneeded characters.
3. Commit and push the changes back to this repository.

## Source lists
- [ADGuard DNS Filter](https://adguardteam.github.io/HostlistsRegistry/assets/filter_1.txt)
- [AdAway Default Blocklist](https://adguardteam.github.io/HostlistsRegistry/assets/filter_2.txt)
- [OISD Block list small](https://adguardteam.github.io/HostlistsRegistry/assets/filter_5.txt)
- [NSFW OISD](https://nsfw.oisd.nl/)
